## Restore instructions

Copy the contents of the selected version folder back to the repository root, preserving the folder structure. Do not copy the enclosing version folder into the root as a nested directory. Restore the package manifest and lockfile together. Environment files and secrets are intentionally excluded and must be configured separately.
