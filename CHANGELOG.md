# Changelog

All notable changes to this project are documented here. This changelog follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses semantic versioning.

## [Unreleased]

### Changed

- Reframed the site as a concise German Empire history resource (1871–1918) with an imperial-era landing page, overview, and updated metadata.
- Added a Germany 1914 geographic orientation map, Hohenzollern and Bismarck family trees, and clear notes where modern borders differ from historical ones.
- Added HOI-style 1×/2×/3× simulation speed, hourly skips, a direct timeline scrubber, and time-aware battle updates to the Verdun 3D feature.
- Replaced Verdun-specific trainer content with questions, glossary entries, and dates about the Kaiserreich; refreshed navigation, search, and sources.
- Added responsive layout styling and generated an era-appropriate Reichstag hero image.

## [1.0.0] - 2026-11-11

### Added

- Initial complete runnable baseline snapshot in `versions/v1.0-baseline/`.
- German learning content for the 1916 Battle of Verdun, including a timeline, glossary, building guide, knowledge check, and interactive trainer.
- Responsive layouts and touch-friendly controls for iPhone, iPad, Mac, PC, and laptop browsers, including Safari safe-area support.
- Fallback-version manifest, restore guidance, and prepared GitHub Release notes.
