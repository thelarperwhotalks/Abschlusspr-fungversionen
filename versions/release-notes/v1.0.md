# Verdun 1916 v1.0

## Summary

Initial runnable baseline release for the Verdun 1916 learning website.

## Included

- A German-language overview of the 1916 Battle of Verdun with historical context, timeline, glossary, and sources.
- An explorer-map project guide, step-by-step model-building instructions, quiz, and interactive knowledge trainer.
- Responsive, touch-friendly support for iPhone, iPad, Mac, PC, and laptop browsers, with Safari safe-area handling.
- A complete source snapshot in `versions/v1.0-baseline/` for fallback and restoration.

## Restore

Copy the contents of `versions/v1.0-baseline/` back to the repository root, preserving its directory structure. Configure environment variables separately; secrets and `.env` files are not included.

Suggested Git tag: `v1.0`
